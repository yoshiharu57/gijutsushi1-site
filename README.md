# 根拠でわかる技術士一次（建設）— 公開ページ

App Store Connect で必須になる2つのURLを置くための、静的サイトです。

- `index.html` … サポートページ（App Store Connect の「サポートURL」に指定）
- `privacy.html` … プライバシーポリシー（同「プライバシーポリシーURL」に指定）

アプリ本体のリポジトリとは分けてあります。本体は非公開、このページだけを公開するためです。

## 公開の手順（GitHub Pages）

1. GitHub で**公開（Public）**のリポジトリを新しく作る
2. このフォルダの中身をそのまま push する
3. リポジトリの Settings → Pages → Source を `main` ブランチのルートに設定
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で見えるようになる

公開後のURL:

- サポートURL … `https://<ユーザー名>.github.io/<リポジトリ名>/`
- プライバシーポリシーURL … `https://<ユーザー名>.github.io/<リポジトリ名>/privacy.html`

## 提出前に必ず直すところ

- [ ] `index.html` と `privacy.html` の「（ここに連絡先メールアドレスを記入）」を実際の連絡先に置き換える
- [ ] 公開後、**実際にブラウザで開いて中身が表示されるか**確認する
      （中身のないURLは「内容が確認できない」と指摘されます）
- [ ] 収録内容が練習問題から過去問題に変わったら、`index.html` のFAQを更新する
